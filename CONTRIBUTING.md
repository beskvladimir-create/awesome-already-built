# Contributing

- **New idea:** open an issue `idea: <one English line>`; say the job the tool does, not the product it serves ("back up Claude Code sessions", not "a Claude Code thing").
- **Your row:** edit the page under `ideas/` and open a pull request. Keep the table format. A feature claim must be visible in your README.
- **Missing repository:** add a row with the repository, stars, last push and features, in the stars order.
- **Removal:** if your repository does not do the job on the page, say so in a pull request and it goes.

Pages are regenerated from time to time; hand edits that disagree with the repository's own description are kept only if the description changes too.
